# Storybook Packager
<sub>1.9.8</sub>

Storybook Packager is a native macOS application for authoring [Storybook+](https://github.com/uwex-learning-tech/sbplus-v3) presentations.

## System Requirments
* macOS 10.15 or later

## Project Requirements
* macOS 10.15 or later
* Xcode 13 or later
* Swift 5
* GitHub
