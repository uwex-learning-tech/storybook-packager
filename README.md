# Storybook Packager
1.0.0-BETA

## System Requirments
* macOS 10.12 or later

## Required Dependency Mangagers
* [CocoaPods](https://cocoapods.org/)
* [Carthage](https://github.com/Carthage/Carthage)

**Before opening the Xcode project, make sure to install the dependency managers and have all of the dependencies installed.**

## Installing dependecies
1. Launch Terminal.app
2. Navigate (`cd`) to `StorybookPackager` project root directory
3. CocoaPods: `pod install`
4. Carthage: `carthage update`

**Do not open the project by launching the `Storybook Packager.xcodeproj` file. Open the `Storybook Packager.xcworkspace` instead.**

## Opening Xcode Project workspace through Terminal.app (if preferred)
1. Launch Terminal.app
2. Navigate (`cd`) to `StorybookPackager` project root directory
3. Run the command `open Storybook\ Packager.xcworkspace`
