• Now supports bundle page type.
  • All quiz types (short answer, fill in the blank, multiple choice, and multiple answer) are now supported.
  • Improved + Page button to add new page after the currently selected page. If no page is currently selected, add new page to the end.
  • Improved + Section button to add new section after the currently selected page. If no page is currently selected, add new section to the end.
  • Delete (trash icon) button will now delete selected pages and then select the previous page of the first deleted page.
  • Bulk drag and drop files will now recognize and create bundle page type if files are correctly named. For example, whatever01-1.svg, whatever01-2.svg, whatever01-3.svg, and whatever01.mp3 will create a bundle page type if they do not exist already. Existing files will be replaced.
  • Bulk drag and drop area has been moved to the top of the page outline view.
  • Replaced program JSON url, author JSON url, and author repo input fields in the Preferences panel with an input field to hold the url to the Storybook's manifest.json file.
  • Minor UI tweaks.
  • Backend updates and improvements.
