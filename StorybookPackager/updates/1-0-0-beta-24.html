• Please read the release notes.
  • Please keep reporting issues even if you are not sure. Thank you!
  • Added New Section and New Page menu items to the Edit menu.
    Notes: because the Edit menu items change based on the UI in focus (or in the responder chain), these two new menu items are enabled only when the interacting with the page outline (left) area.
  • Newly added bundle frame timecode will now always increment time by one second from previous frame timecode.
  • Prevent bundle frames from having the same timecode.
  • Bundle frame timecode is now sanitized and forced to be either one of following formats: 00:00 or 00:00:00. The seconds part can be more than 2 digits. For example: 00:120 = 02:00, 00:90 = 01:30, 00:001234 = 00:00, etc.
  • Empty placeholder page(s) is now added when there is a gap in page numbering during drag and drop. For example, you have 5 pages in the app, but you drag and dropped a file that has a number 20 at the end of it file names. Page 6 to 19 will be automatically added to fill the gap.
  • The add (+) bundle frame button can now select multiple image files to be added to the bundle. Frame for each image will be created with timecode incremented by 1 section from previous frame.
  • The app no longer requires or forced to have at least one page in the page outline.
  • Fixed an issue where app crashed after changing an existing page type to bundle type by drag and drop.
  • Fixed an issue where files are deleted after adding a new page between existing pages.
  • Fixed an issue where bundle frame image preview is not updated after replacement.
  • Fixed an issue where the Import button is not allowing image selection.
  • Fixed an issue where adding audio files first cause image misplacement later, especially when files are named different but ends with a corresponding number.
  • Minor fixes and tweaks.
