  • Please keep reporting issues even if you are not sure. Thank you!
  • Added a new Insert menu to the App menu bar.
  • Added a new Download Files.. menu item to the new Insert menu. Tentatively, this menu item functions the same as the Insert download files button on the toolbar.
  • Added a new Delete Page menu item under the Edit menu.
  • Added a Prevent Autoplay check box to appropriate page types to accommodate the new preventAutoplay attribute introduced in Storybook+ version v3.2's XML.
  • New Page and New Section menu items are moved from the Edit menu to the new Insert menu, and they are now always enabled.
  • + Page button is now placed before + Section button.
  • New Page / + Page now has a shortcut key: ⇧⌘N (Shit+Command+N).
  • New Section / + Section now has a (tentatively) shortcut key: ⌥⇧⌘N (Option+Shift+Command+N)
  • Import button is removed from the toolbar and is now located under the File menu as an Import... menu item.
  • Updated tooltip for Insert download files button on the toolbar.
  • Disabled and hid unrelated/unneeded menu items from menus in the App menu bar.
