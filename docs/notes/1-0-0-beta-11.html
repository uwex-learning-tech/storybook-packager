• Import files by browsing or drag and drop functionality is now functional. Existing files will be replaced. New files will created pages with corresponding page type. That is, if the dropped files contain an image and an audio with name ended with matching number (01 or 1 does not matter) will create a new page with page type of image-audio.

    For example, whatever1.svg and whatever01.mp3 will create a page type of image-audio. The whatever part can be named whatever it needs to be.

  • NSCollectionView for displaying pages is now been replaced with NSOutlineView. NSOutlineView provide better (correct) dragging indicator. Dragging and dropping multiple page items is now supported as well.
  • Document will now only create sub folder in Assets folder when needed. That is, no empty folders.
  • Delete button is now always shown on the touch bar, right after the +Section and +Page buttons.
  • Deleting a page item will now also delete its corresponding assets files.
  • Existing downloadable file indicator color is now white instead of green.
  • Downloadables tab now accepts drag and drop for multiple files instead of one by one for each downloadable file.
  • Downloadables tab now also accepts drag and drop file when the window is not active.
  • Adjusted table cell height for files listed under Assets tab.
  • File listed under Assets tab are now sorted alphabetically.
  • Updated Sparkle Update Framework to version 1.21.3.
  • Fixed an issue where delete button key equivalent is not working.
  • Fixed an issue where Files dialog opened after closing Properties and Settings dialog.
