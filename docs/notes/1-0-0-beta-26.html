• Please read the release notes.
  • Storybook Packager should now work on macOS Catalina (10.15).
  • Please keep reporting issues even if you are not sure. Thank you!
  • Added a Default Player check box to YouTube page type to accommodate the new useDefaultPlayer attribute introduced in Storybook+ version v3.2's XML. This check box will be checked by default. Uncheck it to have the YouTube video uses YouTube Player UI instead of the default player UI.
  • Adjusted scrolling speed for page outline view.
  • Generated XML now only contains attributes that affect the type of the page. (i.e., if the page type is image, attributes such as preventAutoplayer, embed, useDefaultPlayer, etc. will not be generated.)
